# 4. Use Professional Dark Mode with Dynamic Logo Placement

Date: 2026-08-11

## Status

Accepted

## Context

We need to establish the visual aesthetic for the informational IG post template. The options were Professional Dark Mode, Bright & Modern, or Geometric & High Contrast. Additionally, we need a standard place for the organizational logo (`JRI_LOGO.png`).

## Decision

We will use **Professional Dark Mode (專業深色)**. The template will feature a dark background with premium, high-tech, or authoritative highlights. The JRI_LOGO will be included in the bottom-left or bottom-right corner, and we will build a toggle in the web interface (control panel) so the user can decide the logo's position dynamically on a per-post basis.

## Consequences

* **Positive:** Dark mode provides a strong, authoritative, and modern look, suitable for professional administrative announcements. The dynamic logo toggle provides layout flexibility if the text needs more space on one side.
* **Negative:** Dark backgrounds require careful contrast management for text readability, particularly for secondary elements.
