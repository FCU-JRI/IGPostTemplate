# 1. Use automated tools for social media templates

Date: 2026-08-11

## Status

Accepted

## Context

We need to generate templates for Instagram posts and other social media accounts. The two main approaches are using traditional graphic design software (Canva, Figma, Illustrator) manually, or building a programmatic/automated workflow using web technologies (HTML/CSS) to generate images. 

## Decision

We will use an automated/programmatic tool approach to generate social media templates. 

## Consequences

* **Positive:** Allows for bulk generation, strong brand consistency, and integration into automated workflows or CMS in the future.
* **Negative:** Requires initial setup time to build the templates in code compared to dragging and dropping in a GUI design tool.
