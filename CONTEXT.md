# Domain Glossary

## Core Concepts

* **Informational Post Template**: A social media graphic template designed to convey knowledge, explain policies, or provide structured information. It typically consists of a large headline, an optional subtitle, a body text area, and brand elements (like a logo).
* **Global Gallery (images)**: The global state now supports a gallery model (`images: []`) to allow layouts to render either single images or multi-image grids seamlessly.
* **Layout H (Adaptive Gallery)**: An intelligent, engineering-aesthetic layout that dynamically morphs its grid structure based on the number of images uploaded (1 to 4+).

## UI/UX Elements

* **Live Preview Panel**: The right-hand side of the web interface where the user sees a real-time rendering of the 1080x1080 image they are building.
* **Control Form**: The left-hand side of the web interface where the user inputs data (Title, Body, multiple Images, etc.) to update the Live Preview.
