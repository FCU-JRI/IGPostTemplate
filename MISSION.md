# Mission

**Why am I learning this?**
I want to understand how my project (IGPostTemplate) gets deployed to the internet, specifically how GitHub Actions and `deploy.yml` work behind the scenes, so that I can maintain, troubleshoot, or replicate this automated deployment process in the future.

**What are the goals?**
- Understand the basic concepts of Continuous Integration/Continuous Deployment (CI/CD).
- Be able to read and explain the structure of a GitHub Actions YAML workflow.
- Know how Vite builds a React app and how GitHub Pages serves it.
